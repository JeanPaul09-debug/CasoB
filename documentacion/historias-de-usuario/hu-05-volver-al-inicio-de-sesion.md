# HU-05 — Volver al inicio de sesión

**Tipo:** Historia de usuario  
**Prioridad sugerida:** media

## Historia
Como usuario, quiero que el sistema cierre el panel cuando ingreso una clave diferente de CLIMA para finalizar el proceso.

## Criterios de aceptación
- [ ] Una clave distinta genera una alerta.
- [ ] El panel se oculta y vuelve a mostrarse el login.
