# HU-01 — Iniciar sesión

**Tipo:** Historia de usuario  
**Prioridad sugerida:** media

## Historia
Como usuario del sistema, quiero ingresar con las credenciales establecidas para acceder al panel de monitoreo.

## Criterios de aceptación
- [ ] Al abrir la página se muestra el inicio de sesión y el panel permanece oculto.
- [ ] CVC / Lluvias permite entrar.
- [ ] Credenciales incorrectas muestran un aviso y mantienen el login.
