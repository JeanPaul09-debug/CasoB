# HU-03 — Ver el cálculo

**Tipo:** Historia de usuario  
**Prioridad sugerida:** media

## Historia
Como usuario, quiero que el sistema procese los datos antes de mostrar el resultado para saber que está realizando el cálculo.

## Criterios de aceptación
- [ ] Antes del resultado aparece “Calculando datos...”.
- [ ] El resultado aparece después del efecto simulado.
- [ ] La fórmula corresponde a la definición confirmada para el caso.
