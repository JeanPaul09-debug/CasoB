# HU-08 — Adjuntar fotografía

**Tipo:** Historia de usuario  
**Prioridad sugerida:** media

## Historia
Como usuario, quiero subir o simular una fotografía de la zona afectada para complementar el reporte.

## Criterios de aceptación
- [ ] Existe una opción para seleccionar o simular una foto.
- [ ] La fotografía se visualiza o queda asociada al reporte según lo implementado.
