# HU-06 — Calcular duración y aplicar ajuste

**Tipo:** Historia de usuario  
**Prioridad sugerida:** media

## Historia
Como usuario, quiero que el sistema calcule la duración y revise la hora de inicio para aplicar el ajuste indicado.

## Criterios de aceptación
- [ ] La duración se calcula en minutos.
- [ ] Se identifica si el evento inicia dentro de 3:00 p. m. a 6:00 p. m.
- [ ] Se aplica 5.3 % según el sentido que confirme el docente.
