# HU-02 — Registrar datos de lluvia

**Tipo:** Historia de usuario  
**Prioridad sugerida:** media

## Historia
Como usuario, quiero ingresar los datos de una zona para registrar un evento de lluvia.

## Criterios de aceptación
- [ ] Se pueden ingresar dirección, hora de inicio, hora de fin, precipitación en mm y nombre del responsable.
- [ ] Los datos se utilizan para generar el registro.
