# RNF-02 — Validación y mensajes

**Tipo:** Requisito no funcional  
**Prioridad sugerida:** media

## Descripción
El sistema debe informar al usuario cuando las credenciales sean incorrectas y debe evitar presentar resultados como si el registro se hubiera completado cuando falten datos obligatorios.

## Criterios de aceptación
- [ ] Las credenciales incorrectas generan un aviso.
- [ ] Los campos obligatorios se revisan antes de procesar.
- [ ] Los mensajes describen el problema de forma clara.
