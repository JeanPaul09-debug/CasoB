# RD-05 — Unidades de registro

**Tipo:** Requisito de dominio

## Regla del caso
La precipitación se registra en milímetros (mm) y la duración del evento se calcula y expresa en minutos.

## Observación
Este requisito recoge una regla o dato propio del Caso B; no representa por sí mismo una pantalla o acción nueva.
