# RF-05 — Gráfica y fotografía de la zona

**Tipo:** Requisito funcional  
**Prioridad sugerida:** alta

## Descripción
El sistema debe guardar cada registro en un Array y utilizar esos datos para dibujar o actualizar barras en un elemento `canvas`. La gráfica debe incluir el estándar de referencia de 14 mm. Debe existir una opción para subir o simular la captura de una fotografía de la zona afectada.

## Criterios de aceptación
- [ ] Los registros se agregan a un Array.
- [ ] La gráfica se representa en un canvas y se actualiza con los registros.
- [ ] Se muestra una referencia de 14 mm.
- [ ] Existe una opción para subir o simular una foto.
