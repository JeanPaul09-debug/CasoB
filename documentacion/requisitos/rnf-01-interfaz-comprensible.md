# RNF-01 — Interfaz comprensible

**Tipo:** Requisito no funcional  
**Prioridad sugerida:** media

## Descripción
La interfaz debe presentar los formularios, botones, mensajes y resultados de manera clara para que el usuario pueda completar el proceso sin confusión.

## Criterios de aceptación
- [ ] Los campos tienen etiquetas comprensibles.
- [ ] Los botones indican claramente su acción.
- [ ] Los mensajes de error y resultado son legibles.
