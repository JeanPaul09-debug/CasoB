# RF-02 — Registro de lluvia y cálculo

**Tipo:** Requisito funcional  
**Prioridad sugerida:** alta

## Descripción
El sistema debe permitir registrar dirección de la zona, hora de inicio, hora de fin, precipitación en milímetros y nombre de quien registra. Debe realizar el cálculo solicitado por el Caso B y mostrar un mensaje simulado de espera: “Calculando datos...” antes de presentar el resultado.

## Criterios de aceptación
- [ ] El formulario dispone de los cinco datos solicitados.
- [ ] El sistema muestra “Calculando datos...” antes del resultado.
- [ ] El resultado se presenta después del efecto simulado.
- [ ] La fórmula se implementa según la aclaración de la guía/docente.
