# RD-03 — Ventana de ajuste horario

**Tipo:** Requisito de dominio

## Regla del caso
El ajuste indicado es de 5.3 % cuando la lluvia inicia entre las 3:00 p. m. y las 6:00 p. m. El enunciado no precisa si el ajuste aumenta o disminuye el valor.

## Observación
Este requisito recoge una regla o dato propio del Caso B; no representa por sí mismo una pantalla o acción nueva.
