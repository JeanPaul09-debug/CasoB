# RNF-04 — Retroalimentación del cálculo

**Tipo:** Requisito no funcional  
**Prioridad sugerida:** media

## Descripción
Durante el tiempo de espera simulado, el sistema debe mostrar un mensaje que indique que está procesando la información.

## Criterios de aceptación
- [ ] Se muestra el texto “Calculando datos...”.
- [ ] El mensaje aparece antes de los resultados.
