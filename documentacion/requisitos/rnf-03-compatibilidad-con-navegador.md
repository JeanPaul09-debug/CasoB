# RNF-03 — Compatibilidad con navegador

**Tipo:** Requisito no funcional  
**Prioridad sugerida:** media

## Descripción
La página debe poder utilizarse en un navegador web moderno con soporte para HTML, CSS y JavaScript.

## Criterios de aceptación
- [ ] La página carga en un navegador moderno.
- [ ] Los controles principales funcionan sin errores visibles.
