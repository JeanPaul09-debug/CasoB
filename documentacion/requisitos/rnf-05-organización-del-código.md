# RNF-05 — Organización del código

**Tipo:** Requisito no funcional  
**Prioridad sugerida:** media

## Descripción
El código debe mantenerse organizado en archivos separados de HTML, CSS y JavaScript, de acuerdo con la estructura del proyecto académico.

## Criterios de aceptación
- [ ] La estructura separa contenido, estilos y lógica.
- [ ] Los archivos están enlazados correctamente.
